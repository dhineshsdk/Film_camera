## Sideways-photo check (#4)
Checked the code path: orientation = accelerometer (updates only when one axis leads by 1.5 m/s2) + the in-memory ROT offset (starts at 0, never reset by lens change or the test series). A flat or tilted phone keeps the last orientation, and a ROT press adds 90 deg to every later shot. Could not reproduce without physically moving the phone, so it stays open: reset ROT on lens change / test-series start and show ROT in the HUD.
